# Legacy Docs

This folder stores documentation that has been superseded but is kept for historical context.

- `docs/legacy/handovers/`: old architecture handovers and transition guides
- `docs/legacy/superseded/`: replaced manuals/procedures and duplicate copies
- `docs/legacy/v0.x_archive/`: archived v0.x-era notes

Do not use these as the source of truth for current behavior; prefer `README.md`, `USER_MANUAL_V1.0.md`, and active docs listed in `docs/README.md`.
